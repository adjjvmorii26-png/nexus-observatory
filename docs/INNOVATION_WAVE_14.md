# Innovation Wave 14 — Constellation Experiment Seeds

These are deliberately small, reversible experiments derived from the current repository topology and the unusual primitives already present across the constellation.

## 1. Bridge Compiler
Interstice bridge cartography + IXpansion bridge directories + Nexus orchestration.
Compile an untouched repo-to-organ resonance into a concrete bridge specification: evidence paths, event vocabulary, owner, rollback rule. New bridges start quarantined and require human promotion.

## 2. Temporal Replay Chamber
Chronocrypt Orrery + Nexus journal + Pentaxis deterministic RNG/save system.
Record an experiment as an event stream and replay it against multiple engine versions. Compare state hashes and surface the first divergence.

## 3. Forgetting Budget
Antimemetic Architecton + memory crystals + decay curves.
Give every stored memory a bounded retention budget and explain why it survived, decayed, compacted, or was deliberately forgotten.

## 4. Phase-Shifting Workloads
Phaseshift Manifold + Workforce orchestration.
Allow a task to move between solid/deterministic, liquid/adaptive, gas/speculative, and plasma/high-parallelism execution modes while preserving one task contract.

## 5. Echo Parliament Tournament
Polychron Atlas + Choir/Cantor patterns.
Run independent solution agents, hide identities, then have a second-stage parliament judge evidence rather than author reputation. Disagreement becomes an evidence bundle.

## 6. Resonance Market
Interstice latent resonance + Nexus resonance bus.
Treat unused bridges as proposals with cost, expected information gain, and expiry. Experiments compete for a limited attention budget.

## 7. Shatter-and-Suture Fault Lab
Luminant Reliquary + Chronocrypt fracture/suture concepts.
Inject controlled corruption into a copy of an artifact, measure blast radius, then test whether provenance and recovery metadata can reconstruct it.

## 8. Waveform Memory
Echotide tidal memory + audio/visual interfaces.
Represent selected metric histories as compact waveforms so recurring failure signatures can be clustered by shape before exact semantic matching.

## 9. Five-Dimensional State Probes
Pentaxis 5D engine + Nexus metrics.
Expose five independent experiment dimensions: correctness, latency, novelty, reversibility, and explanatory evidence.

## 10. Organism Migration Game
IXpansion deployment matrix + Codex missions.
Model migration as a state machine: observe, shadow, dual-run, cutover, verify, rollback-window, retire. Every transition emits evidence.

## 11. Anti-Memetic Canary
Aegis/security controls + Antimemetic Architecton.
Place harmless synthetic secret-shaped canaries in test fixtures and verify scanners, logs, artifacts, and agents do not propagate them.

## 12. Living Repository Genome
Codexskills registry + Nexus Observatory.
Generate a compact genome for each repository from its tree: languages, runtime, agent instructions, CI topology, deployment hints, bridge count, test surface, and experimental vocabulary.

## Experiment rule
Every seed needs a hypothesis, reversible implementation, observable artifact, falsification condition, and human promotion gate.
Novelty alone is not evidence. Promote experiments when their evidence is useful.
